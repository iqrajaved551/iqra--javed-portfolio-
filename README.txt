IQRA JAVED PORTFOLIO
=====================

This is a responsive one-page portfolio website.

Files:
- index.html = complete website

To publish it for free:
1. Create a GitHub account.
2. Create a new public repository named: iqra-javed-portfolio
3. Upload index.html.
4. Open Settings > Pages.
5. Select Deploy from branch > main > /(root), then Save.
6. GitHub will give you a portfolio link.

Before publishing:
- Replace the LinkedIn and Fiverr placeholder links with your real profile links.
- You can add real project images later.
- The current portfolio projects are sample/concept work unless you replace them with client work.
